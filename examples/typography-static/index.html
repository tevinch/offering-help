A short guide to a quiet workspace

Good documentation should stay readable when it arrives as plain HTML, including content rendered from Markdown.

Start with a clear heading and a paragraph. Explore the text sizes, use emphasis where it matters, and keep inline code legible.

Set up the page

  • Keep the article in a prose container.
  • Use the published file as a normal CSS asset.
  • Choose one of the included sizes or gray themes.

A stylesheet can travel with the document. It does not need a runtime on the reader's site.
